# Local face model assets

These model definitions and weights are copied from `@vladmandic/human` 3.3.6 and are served from this application so the browser does not need a model CDN. The Human library license is included in `HUMAN-LICENSE.txt`.

Models used:

- `blazeface`: MediaPipe face detection
- `facemesh` and `iris`: MediaPipe face landmarks and blink gestures
- `faceres`: HSE FaceRes face descriptor
- `antispoof` and `liveness`: lightweight indicators included by Human for presentation-attack/liveness analysis

See the [Human model credits](https://github.com/vladmandic/human/wiki/Models) and the original model cards/licenses for attribution and redistribution terms. The library's MIT license does not replace any separate terms that apply to an upstream model or its training data.
